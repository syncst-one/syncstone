## What's new

**Notes stay where they belong**
- When a note is renamed or moved on another device while it is open on this one, its text now always stays in that note. Before, in rare cases the text could end up in a different note.
- Swapping the names of two notes (or renaming several in a circle) now arrives on your other devices exactly as you did it.
- If a file was changed differently on two devices, the version that does not win is always kept as a copy next to it. This now also works for images, PDFs and very large notes, not only for normal notes.

**Version history while editing together**
- Restoring an older version while someone else has the same note open now shows the restored text right away for everyone, and it no longer jumps back to the old text with the next keystroke.
- Anything you typed just before restoring is saved first, so it stays in the history as well.

**A clearer first sync**
- Before the first sync of a vault, Syncstone now shows what it is about to download and upload, instead of a general backup reminder after the installation.
- A shorter, clearer message when many files are missing on a device.

**Update hints**
- Syncstone now tells you when a new version is available: a short notice when Obsidian starts, and a box at the top of the plugin settings with a link to these notes. Nothing is blocked, you update whenever you like.
- Should a future version of the service ever need a newer plugin, Syncstone pauses the sync and tells you to update. Your changes on the device are kept and sync as soon as you have updated.

## Also improved on the service

These came with recent updates of the Syncstone service and the web app, no plugin update needed:

- The web app can export notes to PDF, like Obsidian.
- The graph view in the web app is calmer: labels no longer overlap or blink, and dragging nodes no longer makes the graph shake.
- After signing in for the first time you can set up a passkey as well as an authenticator app.
- Usage data per account is now deleted after 30 days, and the privacy policy describes the server and its logs in more detail.
- Renaming a note on one device can no longer be undone by an edit that another device sends at the same moment.
