## What's new

**More reliable sync**
- Renaming or moving a note on another device while it is open no longer mixes up note contents.
- Restoring an older version while editing together now shows it for everyone right away.
- When two devices change the same file, the other version is always kept as a copy, now also for images and PDFs.

**Clearer first sync**
- Before the first sync, Syncstone shows what it will download and upload.

**Update hints**
- Syncstone now tells you when a new version is available.

## Also improved on the service
- Export notes to PDF in the web app.
- A calmer graph view in the web app.
- Set up a passkey right after your first sign-in.
